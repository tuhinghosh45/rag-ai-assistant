# RAG AI Assistant

A Streamlit-based Retrieval-Augmented Generation (RAG) application using:

- Mistral AI
- HuggingFace Embeddings
- ChromaDB
- LangChain
- Streamlit

## Features

- Upload PDFs
- Chat with documents
- Semantic search
- MMR retrieval
- HuggingFace embeddings
- Streamlit UI
